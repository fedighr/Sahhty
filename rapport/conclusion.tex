\chapter*{General Conclusion}
\addcontentsline{toc}{chapter}{General Conclusion}

This report presented the complete design, development, and evaluation of the Sahhty platform, a mobile health application built for pregnant women, male patients, and doctors. The project was motivated by a simple observation: no existing application addressed all these needs together in a single, accessible, and intelligent tool. Sahhty was built to fill that gap.

Throughout six chapters, the report covered the project context and methodology, the system requirements, the architectural and behavioral design, the machine learning and medication modules, the implementation and user interfaces, and finally the testing and validation activities. Each chapter contributed to building a complete and coherent picture of the platform, from the initial problem to the final working result.

The platform achieves its main objectives. Health measurements are automatically analyzed after each submission, and a clear warning is displayed when the situation requires attention. Real-time notifications keep patients and doctors informed of new appointments and medical file access requests. The medication module offers pregnancy safety classification, allergy conflict detection, and interaction analysis between active ingredients. Doctors can request access to patient health documents, and patients retain full control over who can view their data. A smartwatch connection records heart rate passively every thirty minutes. The visual design adapts to each user role through distinct color themes, and the application supports both French and English.

Some limitations remain. The platform currently runs on a local server and would need to be deployed online before reaching a wider audience. The risk analysis model would benefit from a larger training dataset reviewed by medical specialists. Future work could include online deployment, improved risk prediction, a doctor-side patient monitoring dashboard, in-app messaging, video consultations, support for additional smartwatch models, and an administrator interface for platform management.

This project was a demanding and genuinely rewarding experience. It required learning new tools, making decisions under time constraints, and coordinating two development areas in parallel. We are proud of what was achieved and convinced that Sahhty provides a solid and expandable foundation for a useful digital health companion.
